# US-16 — Comparar com o último preço válido correto

## Descrição

Como usuário autorizado da loja, quero comparar cada novo preço com o último preço válido do mesmo item e fornecedor, para identificar a variação real.

## Critérios de aceitação

- [ ] Comparar mesma identidade comercial, fornecedor, modalidade, unidade e embalagem; sem conversão não misturar bases.
- [ ] Usar último preço válido anterior pela ordem comercial, mesmo se item não estava no PDF imediatamente anterior.
- [ ] Ignorar inválidos, pendentes e valores substituídos por correção como base válida.
- [ ] Importação retroativa e correções recalculam comparações afetadas sem apagar rastreabilidade.
- [ ] Empate de preço para mesma apresentação/data exige ordem ou substituição indicada pelo usuário, nunca decisão silenciosa.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
