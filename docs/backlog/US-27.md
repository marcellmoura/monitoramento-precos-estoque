# US-27 — Avaliar leitura de PDFs digitalizados com OCR

## Descrição

Como usuário autorizado da loja, quero extrair informações de PDFs digitalizados, para conferir tabelas que não possuem texto selecionável.

## Critérios de aceitação

- [ ] Escolher ferramenta, dependências, limites e critérios de legibilidade antes de implementar OCR.
- [ ] Distinguir reconhecimento de caracteres de interpretação das informações comerciais.
- [ ] Apresentar o resultado para conferência e manter erros/incertezas pendentes.
- [ ] Documento ilegível não deve virar importação validada; testar pelo menos uma digitalização legível e uma ilegível.
- [ ] Esta evolução depende de avaliação técnica específica, com limites de formatos documentados.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
