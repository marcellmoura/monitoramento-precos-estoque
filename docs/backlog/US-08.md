# US-08 — Extrair itens dos PDFs de referência do professor

## Descrição

Como usuário autorizado da loja, quero extrair itens dos dois formatos de referência, para transformar as tabelas dos fornecedores em dados conferíveis.

## Critérios de aceitação

- [ ] Ler os dois PDFs originais, identificando suas duas linhas e valores 32 e 78; extrair referência, descrição, unidade/embalagem, quantidade e todas as colunas de preço quando disponíveis.
- [ ] Preservar ausência de campos e diferenciar KG/Fardo de ATACADO/VAREJO; não inventar unidade/fator de conversão.
- [ ] Mostrar dados para configuração/conferência AP04; só promover preço de compra após escolha de coluna e base comercial compatível.
- [ ] Usar PDFBox para extração e interpretação própria testável; não usar nome do arquivo ou produto como regra de negócio.
- [ ] Verificar suporte conjunto com US-22 e não tratar varejo do fornecedor como venda interna.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
