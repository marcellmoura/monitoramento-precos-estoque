# US-23 — Sinalizar oportunidades de reposição

## Descrição

Como usuário autorizado da loja, quero visualizar oportunidades de reposição, para identificar produtos cujo estoque precisa de atenção.

## Classificação

| Campo | Valor |
|---|---|
| Tipo | História de usuário |
| Épico | Evoluções |
| Escopo | Evolução |
| Prioridade | Média |
| Status inicial | Backlog |
| Estimativa | A definir |
| Responsável previsto | marcellmoura |
| Perfis autorizados | Administrador, Estoque |
| Fase / marco | P13a |
| Referências | Guia seção 3.2 |
| Testes / evidências | T01 + testes de limites de estoque |
| Depende de | US-03, US-34 |
| Especificação e pré-requisitos | D08, D10, D14 |

## Critérios de aceitação

- [ ] Alertar somente produtos ativos com estoque atual <= mínimo; ambos zero também alertam.
- [ ] Mostrar produto/unidade/estoque atual/mínimo e motivo, conforme perfil Administrador/Estoque.
- [ ] Testar abaixo, igual, acima do mínimo e produto inativo.
- [ ] Não criar compras, alterar estoque ou sugerir quantidade de compra automaticamente.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
