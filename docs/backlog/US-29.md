# US-29 — Entrar com e-mail e senha

## Descrição

Como usuário ativo, quero entrar com e-mail e senha para acessar as funcionalidades do meu perfil.

## Critérios de aceitação

- [ ] Validar e-mail/senha e status ativo sem expor senha/hash na resposta ou logs.
- [ ] Autenticar com Spring Security e persistir sessão via Spring Session JDBC/PostgreSQL.
- [ ] Cookie de sessão HttpOnly/SameSite configurado, Secure com HTTPS; CSRF integrado ao React.
- [ ] Senha temporária dá acesso apenas ao fluxo necessário para trocar senha e sair até concluir a troca.
- [ ] Testar credenciais corretas/incorretas, usuário inativo e primeira senha.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
