# US-28 — Consultar indicadores gerenciais especificados

## Descrição

Como usuário autorizado da loja, quero consultar indicadores gerenciais, para resumir a situação dos preços e importações.

## Classificação

| Campo | Valor |
|---|---|
| Tipo | História de usuário |
| Épico | Evoluções |
| Escopo | Evolução |
| Prioridade | Média |
| Status inicial | Backlog |
| Estimativa | A definir |
| Responsável previsto | marcellmoura |
| Perfis autorizados | Conforme indicador: Administrador/Compras ou Administrador/Estoque |
| Fase / marco | P13c |
| Referências | Guia seção 3.2 |
| Testes / evidências | Conferência dos indicadores contra dados-base |
| Depende de | US-17, US-19, US-34 |
| Especificação e pré-requisitos | D14 |

## Critérios de aceitação

- [ ] Resumo da importação selecionada conta aumentos, reduções, sem alteração, novos e pendentes.
- [ ] Resumo de estoque conta produtos ativos em alerta, conforme atual <= mínimo.
- [ ] Permitir conferir dados-base e recorte; não misturar preços válidos e pendências.
- [ ] Dados de importação/custos somente Administrador/Compras; alertas Administrador/Estoque.
- [ ] Testar com massa conhecida e estado sem dados, sem acrescentar métricas de vendas/compras inexistentes.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
