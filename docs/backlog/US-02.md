# US-02 — Consultar produtos e seus dados

## Descrição

Como usuário autorizado da loja, quero consultar os produtos cadastrados, para verificar catálogo, preços e estoque.

## Critérios de aceitação

- [ ] Listar produtos persistidos e permitir consultar seus dados RF01.
- [ ] Mostrar corretamente unidade, preços, estoque atual/mínimo e status.
- [ ] Apresentar estado compreensível quando não houver produtos e quando ocorrer falha; consulta não altera dados.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
