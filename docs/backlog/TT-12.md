## Critérios de aceitação

- [ ] Executar exclusivamente pelo README e importar dois PDFs compatíveis do mesmo fornecedor com histórico/comparação.
- [ ] Demonstrar aumento, redução, igualdade, novo e pendente; confirmar se massa sintética é aceita pelo professor.
- [ ] Mostrar testes críticos passando no Actions, PR com revisão/integração, Compose e logs.
- [ ] Reunir links de commits, execuções e análises; confirmar prazo/formato no Classroom.
- [ ] Validar evoluções P13a–P13d separadamente em P14; não condicionar a definição do MVP do professor ao OCR proposto.
- [ ] Registrar submissão/apresentação real antes de afirmar entrega concluída.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
