# US-11 — Associar manualmente item ao produto interno

## Descrição

Como usuário autorizado da loja, quero associar um item do fornecedor a um produto interno, para reconhecer a correspondência comercial correta.

## Classificação

| Campo | Valor |

| Tipo | História de usuário |

| Fase / marco | P8 / E2 |
| Referências | RF03, RF06, RB04, RB05 |
| Testes / evidências | T05, T08 |
| Depende de | US-02, US-09, US-34 |
| Especificação e pré-requisitos | D06 |

## Critérios de aceitação

- [ ] Administrador/Compras confirmam na primeira importação o vínculo entre item/apresentação e produto interno.
- [ ] Persistir por fornecedor, referência quando existir, unidade e embalagem; código isolado não é identidade universal.
- [ ] Nome parecido apenas sugere; falta de apresentação ou identificação incerta mantém pendência para confirmação.
- [ ] Permitir cadastrar produto inexistente por perfil autorizado e retomar associação sem conceder acesso indevido.
- [ ] Testar nomes/códigos repetidos em fornecedores/apresentações distintos.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
