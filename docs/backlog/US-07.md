# US-07 — Consultar tentativas e status de importação

## Descrição

Como usuário autorizado da loja, quero consultar as tentativas de importação, para acompanhar sucessos, falhas e pendências.

## Classificação

| Campo | Valor |
|---|---|
| Tipo | História de usuário |
| Épico | Importação e Conferência |
| Escopo | MVP obrigatório |
| Prioridade | Alta |
| Status inicial | Backlog |
| Estimativa | A definir |
| Responsável previsto | marcellmoura |
| Perfis autorizados | Administrador, Compras |
| Fase / marco | P6 / E2 |
| Referências | RF04, RF09 |
| Testes / evidências | T03, T10 |
| Depende de | US-06, US-34 |
| Especificação e pré-requisitos | D07 |

## Critérios de aceitação

- [ ] Mostrar fornecedor, data, arquivo, contagem de itens quando disponível e status de cada tentativa.
- [ ] Permitir abrir detalhes e consultar erros/pendências identificados.
- [ ] Manter tentativas com falha ou duplicidade visíveis; não atribuir quantidade fictícia a arquivo não extraído.
- [ ] Contagens e estados seguem a definição definida em D07.

- [ ] Acompanhar processamento assíncrono pelo ID; mostrar aguardando conferência, falha e concluída com pendências coerentes com os itens.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
