# TT-06 — Executar build e testes no GitHub Actions

## Descrição

Executar verificações automáticas em push/PR e impedir aprovação falsa de builds/testes com falha.

## Critérios de aceitação

- [x] Configurar eventos e branches especificados; executar build/testes backend e frontend.
- [x] Ajustar diretórios backend/frontend e caminhos de relatórios.
- [x] Falha de build ou teste reprova o workflow sem continue-on-error mascarando resultado.
- [x] Inspecionar execução real vinculada ao commit; incorporar suítes novas conforme forem implementadas.

- [ ] Quality Gate reprovado falha a verificação de qualidade; CI não deve mascarar o resultado.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
