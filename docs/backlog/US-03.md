# US-03 — Editar produto e dados básicos de estoque

## Descrição

Como usuário autorizado da loja, quero editar os dados de um produto, para manter cadastro, preços e estoque atualizados.

## Classificação

| Campo | Valor |
|---|---|
| Tipo | História de usuário |
| Épico | Produtos e Estoque |
| Escopo | MVP obrigatório |
| Prioridade | Alta |
| Status inicial | Backlog |
| Estimativa | A definir |
| Responsável previsto | marcellmoura |
| Perfis autorizados | Administrador; Compras nos campos permitidos; Estoque nas quantidades |
| Fase / marco | P5 / E1 |
| Referências | RF01, RB09, RB12 |
| Testes / evidências | T01 |
| Depende de | US-02, US-34 |
| Especificação e pré-requisitos | D08, D10 |

## Critérios de aceitação

- [ ] Editar campos RF01, aplicar validações AP01/AP03 e mostrar valores após salvar; não sobrescrever histórico importado.
- [ ] Somente Administrador altera venda após cadastro e configura margem. Compras escolhe referência de compra e edita dados permitidos; ajustes posteriores de estoque são Administrador/Estoque.
- [ ] Unidade com vínculos/histórico não pode mudar por edição simples; fluxo controlado deve ser apresentado antes de implementado.
- [ ] Importar cotação não altera estoque, venda ou compra interna automaticamente; guardar ator de ajuste de estoque.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
