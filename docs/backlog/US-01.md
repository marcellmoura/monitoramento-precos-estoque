# US-01 — Cadastrar produto interno

## Descrição

Como usuário autorizado da loja, quero cadastrar produtos com seus dados básicos, preços e estoque, para manter o catálogo organizado.

## Classificação

| Campo | Valor |
|---|---|
| Tipo | História de usuário |
| Épico | Produtos e Estoque |
| Escopo | MVP obrigatório |
| Prioridade | Alta |
| Status inicial | Backlog |
| Estimativa | A definir |
| Responsável previsto | marcellmoura |
| Perfis autorizados | Administrador, Compras (venda inicial) |
| Fase / marco | P5 / E1 |
| Referências | RF01, RB12 |
| Testes / evidências | T01 |
| Depende de | TT-03, TT-04, US-34 |
| Especificação e pré-requisitos | D08 |

## Critérios de aceitação

- [ ] Oferecer campos RF01; exigir nome, unidade e preço de venda. Gerar código interno separado da referência do fornecedor.
- [ ] Categoria opcional; compra pode ficar ausente, sem converter ausência em zero. Estoques inicialmente zero e status ativo.
- [ ] Impedir preços/estoques negativos; venda zero permitida. Persistir cadastro válido e disponibilizar consulta.
- [ ] Administrador e Compras podem cadastrar, inclusive informar venda inicial; alterações posteriores da venda são exclusivas do Administrador.
- [ ] Unidades KG/G/L/ML/UN; estoques até três casas para medidas, inteiros para UN. Testar sucesso, validação e permissões.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
