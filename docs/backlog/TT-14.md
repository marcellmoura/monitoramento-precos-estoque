# TT-14 — Verificar segurança de autenticação e autorização

## Descrição

Validar autenticação e autorização desde os incrementos correspondentes, consolidando evidências de segurança.

## Critérios de aceitação

- [ ] Testes incrementais para CSRF, cookie/sessão, logout, expiração e revogação.
- [ ] Testar acessos negados por perfil e ausência de custos/hash em respostas de perfis restritos.
- [ ] Testar senha temporária, mínimo de caracteres, hash Argon2id e bloqueio de último Administrador.
- [ ] Documentar bootstrap local sem segredo padrão publicado; componentes gerenciados pelo conjunto Spring compatível.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
