# TT-09 — Registrar logs rastreáveis de importação

## Descrição

Permitir diagnosticar início, conclusão e falha de importação.

## Classificação

| Campo | Valor |
|---|---|
| Tipo | Tarefa técnica |
| Épico | Operação e Entrega |
| Escopo | DevOps obrigatório |
| Prioridade | Alta |
| Status inicial | Backlog |
| Estimativa | A definir |
| Responsável previsto | marcellmoura |
| Fase / marco | P6–P12 |
| Referências | RNF07 |
| Testes / evidências | T03, T06, T13 |
| Depende de | US-06 |
| Especificação e pré-requisitos | D07, D15 |

## Critérios de aceitação

- [ ] Registrar início, conclusão e falha com identificador de importação e motivo em caso de erro.
- [ ] Relacionar logs à tentativa consultável e aos itens pendentes quando aplicável.
- [ ] Demonstrar consulta de logs por instrução documentada, incluindo execução em Compose.
- [ ] Não registrar credenciais ou conteúdo integral desnecessário do PDF.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
