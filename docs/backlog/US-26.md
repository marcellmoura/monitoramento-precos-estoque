# US-26 — Conferir e mapear dados de layouts desconhecidos

## Descrição

Como usuário autorizado da loja, quero conferir e mapear campos de PDFs com outros layouts, para ampliar fornecedores sem cadastrar dados incertos.

## Critérios de aceitação

- [ ] Oferecer extração assistida e mapeamento de campos/colunas quando houver informação legível suficiente.
- [ ] Manter dados incertos pendentes, sem inventar unidade ou escolher preço arbitrariamente.
- [ ] Avaliar perfis reutilizáveis de layout por fornecedor; aprovação do perfil não cria vínculo de produto automaticamente.
- [ ] Testar colunas reordenadas, cabeçalho repetido, descrição quebrada e várias páginas.
- [ ] Informar quando o documento não puder ser interpretado com segurança; documentar limites.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
