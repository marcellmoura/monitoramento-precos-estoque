## Critérios de aceitação

- [ ] Fixar versões atuais estáveis e mutuamente compatíveis após consulta oficial, sem prereleases.
- [ ] Frontend React/TypeScript/Vite, React Router, Fetch centralizado e CSS Modules; npm e lockfile.
- [ ] Backend Spring Boot/Maven; wrapper e módulos com HTTP, serviços/regras e persistência separados.
- [ ] Preparar Vitest/React Testing Library e Playwright; backend Spring Boot Test/JUnit/Mockito/MockMvc, Testcontainers/PostgreSQL e JaCoCo.
- [ ] Builds e testes iniciais reproduzíveis; sem funcionalidades fora do incremento definido.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
