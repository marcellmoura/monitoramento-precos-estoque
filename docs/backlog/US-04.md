# US-04 — Cadastrar fornecedor

## Descrição

Como usuário autorizado da loja, quero cadastrar fornecedores, para identificar a origem dos documentos e preços.

## Classificação

| Campo | Valor |
|---|---|
| Tipo | História de usuário |
| Épico | Fornecedores |
| Escopo | MVP obrigatório |
| Prioridade | Alta |
| Status inicial | Backlog |

| Fase / marco | P5 / E1 |
| Referências | RF02 |
| Testes / evidências | T02 |

| Especificação e pré-requisitos | D08 |

## Critérios de aceitação

- [ ] Administrador/Compras cadastram fornecedor com nome obrigatório e código interno gerado.
- [ ] CNPJ, telefone e e-mail opcionais; validar formato de telefone/e-mail quando preenchidos, sem exigir CNPJ.
- [ ] Nomes podem repetir; distinguir por identidade interna. Cadastro fica consultável/selecionável na importação.
- [ ] Testar entradas válidas/inválidas e negar criação por Estoque/Consulta.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
