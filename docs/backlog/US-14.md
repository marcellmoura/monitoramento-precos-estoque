# US-14 — Identificar reimportação do mesmo arquivo

## Descrição

Como usuário autorizado da loja, quero ser avisado ao reenviar o mesmo PDF, para evitar duplicação silenciosa de preços e históricos.

## Critérios de aceitação

- [ ] Detectar conteúdo idêntico mesmo com nome diferente. Mesmo fornecedor: nova tentativa rastreável aponta importação existente.
- [ ] Não duplicar itens/histórico. Retomar pendências na importação existente.
- [ ] Falha técnica permite repetir processamento sem duplicar o que já foi salvo; preservar tentativas.
- [ ] Arquivo igual para outro fornecedor exige confirmação explícita; se confirmada, manter históricos separados.
- [ ] Correção posterior não exige reenvio, seguindo US-35.

## Condições de conclusão

- Atender aos critérios de aceitação e executar os testes pertinentes.
- Aplicar a definição de pronto do índice `docs/backlog.md`.
- Registrar evidências de build, testes e revisão; atualizar documentação e status somente conforme o trabalho realizado.
