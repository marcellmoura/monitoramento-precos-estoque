# PDFs de referência

- `Fornecedor_1.pdf` e `Fornecedor_2.pdf`: exemplos fornecidos na disciplina, preservados sem alterações.
- `sinteticos/`: dados fictícios para testar layouts diferentes e importações sucessivas. Ver [cenários e resultados esperados](sinteticos/LEIA-ME.md).

Os exemplos têm layouts distintos e valores iguais; não constituem versões temporais do mesmo fornecedor. As comparações de aumento/redução usam sequências sintéticas por fornecedor, após cadastro e associação.

Os arquivos são entradas de referência, não evidência de um leitor já implementado. Testes devem verificar valores e regras independentemente do nome dos arquivos/produtos.
